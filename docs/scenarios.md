## Сценарии использования приложения:

1. Создание карточки товара с нулевым количеством

2. Увеличение количества товара с существующей карточкой

3. Уменьшение количества товара с существующей карточкой

4. Изменение цены товара с существующей карточкой

5. Скрытие или восстановление карточки товара с нулевым количеством

6. Поиск списка товаров по категории без авторизации

7. Заказ покупателем указанного числа одного товара

8. Просмотр заказов покупателем

9. Отмена заказа покупателем

10. Просмотр заказов продавцом

11. Отмена заказа продавцом

12. Регистрация покупателя

13. Регистрация продавца

14. Просмотр продавцом своих товаров (все детали по товару и остаток).
